## 无辅助的具体范围

- 只提供原始棋盘、活动块、蛇身、食物坐标、计分状态、游戏规则与固定动作含义。
- 不提供模拟后的结果、合法动作筛选、最佳/安全标签、风险或距离评价、路径搜索、循环检测、教学示例或执行纠错。
- 方块不枚举目标落点，每次模型选一个输入；`hard_drop` 是游戏原有动作，一次算一步，不把下落格数或一个方块拆成多步。
- 蛇使用原始引擎出生位置，不执行循环安全层对蛇身和食物的初始化修改；每个方向动作推进一帧，终局碰撞帧计入步数。
- 500 是上限，提前自然终局就结束，不重开补足。规则校验仍保留；受阻输入或请求失败会单独标为测试停止，不能算作成功存活。

这与旧版“关闭纠错但仍提供最佳候选提示”不同，旧版辅助成绩不能直接对比为 JEV 能力退化。

## 复现与证据

在进程环境配置 `JEV_API_KEY`，从项目根目录启动：

```sh
.venv/bin/python -m uvicorn backend.jev_server:app --host 127.0.0.1 --port 8770
```

另一个终端执行（会调用云端，目标目录必须尚不存在）：

```sh
dart run tool/benchmark_jev_raw.dart tetris reports/local/jev-raw/tetris 20260921 500
dart run tool/benchmark_jev_raw.dart snake reports/local/jev-raw/snake 20260921 500
```

本次保存 [方块汇总](tetris/summary.json)、[方块逐步记录](tetris/steps.jsonl)、[蛇汇总](snake/summary.json)、[蛇逐步记录](snake/steps.jsonl)。记录包括每次原始请求、响应、模型选择、实际执行和执行前后状态，不含密钥。

```sh
# 无模型调用：重新计算请求并核对原始选择、棋盘、分数与终局。
dart run tool/verify_jev_raw.dart reports/jev-unassisted/tetris
dart run tool/verify_jev_raw.dart reports/jev-unassisted/snake
```

已核验全部 11/9 步请求、原始选择、实际执行与确定性回放一致。前端和测试脚本共用 `lib/unassisted.dart` 的请求生成逻辑与游戏引擎。新增测试覆盖不筛除致命或受阻动作、混合竞技中 JEV 不纠错、独玩选择 JEV 后辅助开关禁用。

工程验证：`flutter analyze` 无问题，`flutter test` 51 项通过，`flutter build web` 通过（含 Wasm dry run）。后端代理未修改，本次未重跑 Python 测试。
