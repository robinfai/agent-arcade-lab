# Astra 逐格试玩：单局结果

种子 20260920，与 Qwen 新版首局相同；同一 StepTetris 引擎，每次有效动作带一格重力，无踢墙。正常出生受阻结束，无重开、撤销、规则代打或 Qwen 调用。

|分数|2000|0|
|左移|68|0|

|下落|724|58|

Astra 通过控制台读取文本棋盘、当前块位置、下一块、旋转坐标和合法动作，自行指定动作序列。`f` 是显式指定“重复 down 直到当前块锁定”的输入缩写，每一格仍由相同引擎执行并计数；不计算最优落点，不自动选择横移或旋转。部分动作批次跨过了锁定边界，错误保留。因此这是代理交互样本，不是与 Qwen 单次请求预算、上下文和输出协议完全对齐的模型能力基准。没有在浏览器中逐键执行，现有页面对局不变。

## 已观察到的失误

- 第 13、22 块 L 分别新增 3 个空洞，第 31 块 S 新增 4 个空洞。
- 第 68 块 J 在横移途中提前锁定，批次中的最后一次右移作用于新出生的 I，保留后继续。
- 发生两次未计入有效动作的拒绝：有效动作 169 后，横 I 向右越界；有效动作 467 后，T 在最右边旋转越界。后续通过旋转/移开恢复，无回滚。
- 最终第 80 块 S 锁定后，下一块 O 的出生位置受阻。
- 后期高堆叠让远端空列难以到达：左右移动也推进重力，路径中途可能先触地锁定。此现象与本实验规则有关。

## 验证及文件

`dart run tool/verify_astra_step.dart` 从空棋盘独立重建 992 次有效动作，核对 80 块、17 行、2000 分及自然终局。未新增模型性能或全套游戏测试。

- actions.json：实际有效动作序列。
- trace.jsonl：逐动作请求状态、所选动作、执行后棋盘及活动方块。
- replay.json：80 个锁定后的棋盘帧（尚未接入网页回放）。
- validation.json：动作统计与空洞增加点。
- summary.json：终局结果。

本局横向布局明显优于 Qwen 首局，但只有一个种子，不能据此宣称稳定能力或归因于某个单一因素。旧 Astra 硬降局使用不同种子和规则，不能直接比较分数判断逐格是否更好。
