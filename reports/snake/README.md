# 双蛇同帧竞技

页面顶部选择“贪吃蛇”。青色 Laya 421M（8769）和黄色 Qwen3.5-0.8B-4bit（8765）每帧读取结算前的同一局面，各自用相对方向 forward / left / right 决策。两个请求并发发出，全部有效才提交一帧。任何请求失败，整帧保持原样并暂停；没有动作回退或程序代选。

12×12 棋盘；共享一个食物，吃掉后随机刷新于双方均未占据的格子，加 10 分、增长一格。支持随机新局及同种子重开。模型看到双方身体坐标、食物坐标及三个动作的碰撞风险和曼哈顿距离，属于程序提供信息的辅助决策；没有按安全性过滤动作。

头撞墙或任意蛇身失败；双方头到同一格、迎面交换头位置均失败。未吃食物的尾格在该帧腾空，可以进入。双方同时撞同一个食物格时不加分。任意一方失败即结束本局；双败平局。暂停允许当前请求帧完成，新局和切换游戏通过代次标记忽略旧响应。

## 实测

固定种子 20260921，真实双模型共执行 7 帧，Qwen 0.8B 获胜，Laya 碰撞失败，双方均 0 分。模型返回均有效；无程序纠错。此结果只用于验证实战链路，不代表多局能力排名。

- `20260921/frames.json`：双方原始请求、响应及逐帧得分。
- `20260921/summary.json`：结果。
- `tool/benchmark_snake.dart`：复现 `dart run tool/benchmark_snake.dart 20260921`，最多 150 帧；达上限只记停止，不判胜负。
- 35 项 Flutter 测试通过（含 8 项新增竞技规则 / 页面测试）；修改范围静态检查、Web release 构建通过。
- 11 项相关后端测试通过；真实接口联调修复了 Qwen 必需的 `model` 请求字段。

Qwen 启动限制：MLX memory 4096 MiB、cache 256 MiB、wired 2048 MiB；Laya 维持 memory 4096 MiB / cache 256 MiB。内存分配器限制不是整个进程的系统硬限制。Kev 和 DeepSeek 保持关闭。

## 共享后端模型恢复修复

贪吃蛇不再因俄罗斯方块已加载 4B 而返回 409；接口持有可重入锁，在推理前加载所需的 0.8B（已加载时直接复用），并阻止其他请求在加载与推理之间切换模型。加载失败仍返回错误，不替代动作。14 项相关测试通过，包含并发锁及失败不推理检查。实机从 4B 状态自动切换至 0.8B 并返回合法动作，证据见 model-auto-switch.json。
