# 双方统一竞技防循环辅助

默认开启，可在页面关闭；切换会重开。两边使用完全相同的程序算法，不依赖模型概率或模型名称。

每帧读取同一局面，记录最近 20 帧各蛇的头位置与方向（每帧只记一次，食物变化后清空）。三个候选均提供给模型。程序按碰撞风险、重复次数、绕开双方当前身体的 BFS 食物距离、可达空间比较候选。仅在降低碰撞风险、减少重复位置或恢复食物通路时改写模型选择；其他情况保留原动作。没有安全方向时仍只能选择相对较低风险方向，不保证不死。双方选择均在棋盘更新前完成，再统一结算。

关闭开关只关闭动作改写，路径和重复信息仍提供给模型。辅助不是模型独立规划，且不是单蛇 Hamiltonian 安全保证。页面显示双方的原始动作、执行动作、改写原因和累计次数。

实测种子 20260921，150 帧达到测试上限停止，双方仍存活：

| --- | --- | --- |

旧版同种子 150 帧为 0 / 90 分。新旧输入也有变化，不能将差异全部归因于纠错；仅用于观察本次整体更新效果。原始请求、响应、实际动作及逐帧计数见 `20260921/frames.json`。

验证：原有全量测试通过；新增三项测试覆盖双边四步循环纠正、禁用不改写、历史幂等和食物刷新清空。静态检查及 Web release 构建通过。
