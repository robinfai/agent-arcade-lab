# 单蛇社区循环安全策略

独玩默认启用循环安全层，竞技保持原先同帧策略。核心路线和候选判断适配自 `vendor/laya-mlx/laya_mlx/snake/game.py` 和 `policy.py`（Apache-2.0，commit fc1df62828a3fedf4d8229fdac1cbd85f1cdf337）。实现在 `lib/snake_cycle.dart`，游戏碰撞规则仍在 `snake_game.dart`。

- 单蛇使用 UP/DOWN/LEFT/RIGHT，按覆盖全棋盘的闭环初始化身体。
- 安全动作保持身体循环顺序，不越过尾巴，不跳过食物，且沿环正向推进。
- Laya 使用社区 compact 文案，同时询问 move/risk/food。后两项为诊断输出，不影响执行。
- 原始选择安全就照常执行；否则按 Laya 返回的概率，在允许的动作中重新选最高项。UI 显示原始选择、执行动作、纠错次数。
- 可以关闭安全层，直接执行模型结果；切换会重开，避免把已偏离循环约束的身体直接交给安全层。
- Qwen 独玩也使用该路线，但仅调用 move 工具；其工具调用没有概率，纠错时由程序选安全集合中推进最多的方向，页面单独说明。
- 棋盘沿用本项目 12×12、初始长度 3、Dart 随机数；不是社区默认 24×16/长度 6，也不声称与 Python 同种子产生相同食物序列。

## 实测

相同初始化及种子 20260921，每一步真实调用 Laya Multilingual 322M，均测试到 300 帧上限：

| 安全层 | 分数 | 长度 | 存活 | 纠错 |
| --- | --- | --- | --- | --- |
| 关闭 | 90 | 12 | 是 | 0 |
| 开启 | 130 | 16 | 是 | 1 |

原始逐帧模型选择、执行结果及概率保存为 `raw.json`、`guarded.json`。两个实验均因测试上限停止，并非死亡或已填满。当前样本摆脱了旧版连续相对右转的四步循环，但关闭安全层不具有持续进食或不死保证。这里是模型加规划辅助的成绩，不是模型独立规划能力。

程序测试：循环覆盖 144 格并闭合；3 个随机种子任意选择安全候选均最终填满棋盘，且全过程不死亡；纠错遵循安全集合和概率、保留安全原始选择、禁止把单蛇规划用于竞技。全量 41 项 Flutter 测试、静态检查和 release 构建通过。页面验证独玩开关及实际一帧调用，DOWN → DOWN，51 ms。

复现：`dart run tool/benchmark_snake_cycle.dart`；仅重跑无纠错对照：`dart run tool/benchmark_snake_cycle.dart raw`。服务保持端口 8769。
