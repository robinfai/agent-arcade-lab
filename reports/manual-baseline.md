# 手动基准局 · 2026-09-20

已停止新的 Qwen 试玩。本局由 Codex 阅读棋盘、逐步选定旋转/列，通过同一 Dart 游戏引擎执行；不调用 Qwen，不使用启发式选点程序，也没有重开或撤销错误。它是一个可复现的手动选点样本，不是人类玩家群体统计或最优策略。

## 固定基准

| 项目 | 结果 |
|---|---|
| 种子 | 20260921 |
| 有效落块步骤 | **114** |
| 消除行数 | **29** |
| 分数 | **4,300** |
| 结束原因 | 第 115 块 L 无合法落点 |
| 被拒绝的非法尝试 | 1 次，不计落块步数 |
| 消行分布 | 单消 5 次、双消 6 次、三消 4 次、四消 0 次 |
| 模型 API 请求 | 0 |
| 独立重放核验 | 114 帧全部一致 |

规则沿用 10×20、七袋随机、回合制硬降、顶部垂直落入的变体。一“步”指一块锁定，不是一次按键。手动操作通过 `tool/manual.dart` 的显式落点命令执行，Flutter 页面使用同一引擎，保存的棋盘支持页面回放。没有把这些命令说成在浏览器逐次按键操作。

## 失败点：保留原始错误

- 第 23 步 `L / r3x7` 新增 1 个空洞，是第一处空洞增加。
- 第 41 步 `S / r0x0`：对落点高度判断错误，新增 5 个空洞。
- 第 108 步 `J / r2x0`：列位置选错，封住左侧消行井，新增 9 个空洞。
- 随后尝试 `I / r1x0` 被合法性检查拒绝；保留 J 的错误落点，改为 `I / r1x9` 继续。
- 第 112 步顶部 O 仍成功消除一行；第 114 步后下一块 L 无任何合法落点，正常终局。

全局有 15 步出现空洞数增加，完整位置见 `manual-summary.json`。这些动作是分析样本，不能全部当作模型训练的正确答案。

## 后续评估口径（尚未开始新的模型评测）

1. 先固定此种子、方块序列、规则、一步定义，比较存活步数、消行与最终死因。
2. 协议合法、几何合法、策略优劣分开评估。候选约束保证合法，不算模型判断正确。
3. 单独统计新增空洞、封井、遗漏消行；不要只看是否与这局动作完全相同。
4. 手动选点时间不与模型 API 耗时混为一谈。
5. 本局只有一个样本，后续再测试多种子稳定性；当前按用户要求暂停模型试玩。
