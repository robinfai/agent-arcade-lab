# Qwen 4B 辅助规划与直接落位

用户授权程序提供合法落点与结果预测，由 Qwen 选择。程序对每个当前状态穷举符合实际逐格重力的可达锁定位置，计算消行、空洞、堆高、粗糙度及出生碰撞，全部提供给模型，没有启发式排序、裁剪或失败接管。Qwen 只返回原生工具 placement_id，动作路径由搜索器提供，不能称为模型独立学会所有动作。

默认辅助模式：模型每块选一次，按最多八步分批续执行，状态改变则废弃旧方案。关闭长思考，使用短工具输出，保留原始思考接口供对照。直接落位工具 land_at_target 使用相同路径一次执行到锁定，保持碰撞、消行、下一块与计分一致。页面已明确标注辅助程度。

原始自主规划对照（baseline）：16 动作、0 块、0 分；第 3 次调用思考耗尽输出预算，停止，不能算作自然终局。

assisted-20260920 是早期试验：每批重新选择，路径优先级也不同，35 块、5 行、600 分，堆顶结束；不与固定版本合并统计。其旧统计器未记录 token，thinking=null 也不是实际开启思考，实际该接口关闭思考。

final-* 使用固定方案续执行和 down 优先的路径遍历顺序，三个预先选定种子 20260920、20260921、20260922。每局上限 600 动作 / 100 批次，summary.json 标明终止原因。各局 turns.jsonl 保存模型原始工具调用、完整输入 messages、预测和执行结果；续执行行复用原选择响应，不算新模型调用。HTTP 耗时包含其他本机评测请求排队，不能当作独占推理速度。

skills.json：五个不同列的四格深井，当前 I 块横向，需要选旋转和适当横移后的竖直落点。五个均由模型选中四行全消目标，分别得到 800 分。这是简单诊断题，不是自然对局得分，也不证明长程规划能力。

验证：19 项 Flutter 测试、22 项 Python 测试、本次相关 Dart 静态检查与 Web 构建通过。完整项目静态检查此前存在独立 DeepSeek 脚本的括号风格提示，未修改该无关脚本。
