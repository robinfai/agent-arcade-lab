# 相同候选下的模型对照：恢复后汇总

60 个配置现已取得游戏结果。这里汇总的是恢复后的策略表现，不代表原始实验无中断完成。

## 数据选取与结论

保留原始批次 52 个无请求错误的结果；Laya 两个失败配置采用独立重开重试；JEV 六个失败配置采用原局断点续跑。没有按分数择优。来源目录、摘要和最终状态保存在 [results.json](results.json) 的 batch、evidence_path 等字段中。

模型看到完整状态、规则和共同合法候选，无评价标签、无执行纠错。程序仍负责合法动作枚举与路径执行。每局最多 2000 个实际动作。JEV 恢复阶段取消 HTTP 尝试数和总等待时间上限，因此不比较公平延迟或无中断完成率。

## 原始可靠性与恢复

- 原始 60 次尝试：52 次自然结束或预算终止，8 次请求失败。JEV 原始正常结束 6/12，蛇仅 2/6 跑满；Laya 10/12，Qwen 12/12 无请求错误。游戏堆顶和受困也属于有效策略结果。
- 独立重开重试：Laya 两局取得结果，JEV 六局再次遭遇上游 503/529。这六次 JEV 重开尝试不参与策略均值，但保留在可靠性记录中。
- 断点恢复：JEV 六个配置全部取得结果，恢复期间新增失败合计 0 次。每条累计轨迹仍有一次原始失败，不能称为整局零错误。版本保持 jev-1.13.0。
- 原服务退出原因未查明。恢复时补装固定 Laya 子模块解决了重启环境的包缺失；JEV 上游错误与本地连接中断分别记录。
